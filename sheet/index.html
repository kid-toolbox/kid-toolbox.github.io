四线三格 · 正面抄写 / 反面默写

单词

逗号、空格、换行都行。专有名词请保留大写（China）。
满 20 行一页；不足补空白行；超过 20 个自动排成多套。

课本常见的词会自动带上记忆点和分级；其他单词先显示音标和中文。

这张纸怎么用

正面抄写：第一格是范字（浅色底），后面三格临写。反面默写：看中文写英文，写完再看右边的重点音标。

四线三格总高 9mm，和中国小学英语练习本一致。字母 a c e o m n 的高度正好等于中间一格， 头顶贴第 2 条线、底坐第 3 条线（基线）；g p y 的下伸落在第 4 条线以上。

音标（IPA）

本站用英式音标。几个符号：

  • ˈ 主重音，标在重读音节前面（不是元音头上）
  • ː 长音 —— 汉语没有长短对立，孩子容易读短，要拉长
  • æ 汉语没有，嘴巴扁、下巴下沉，介于「埃」和「啊」之间
  • ə 弱读央元音，非重读音节轻轻带过
  • ð 舌尖轻触上下齿，声带振动（不是 d）

自然拼读（拼读切分）

把单词按「哪几个字母发哪个音」切开，例如 l-igh-t、sea-shell。 元音组合整体不拆（ee / igh / ay / ow / ar），因为孩子要记的是「这个组合发这个音」。

分级（CEFR）

标记含义
A1入门级。小学低年级高频词，日常对话立刻能用（pen、boat、teacher）
A2基础级。小学中高年级常见词，能说明身边事物（ocean、artist、jellyfish）
B1进阶级。明显超出日常，通常是阅读里遇到的词（mural 壁画）
B2+流利级，小学阶段基本用不到

用途：判断一个词值不值得现在花时间。满屏 B1 就说明这一课偏难，可以先放过。

词频（★）

星数来自 ECDICT（MIT）里的 bnc / frq 排名，取两者中更靠前的名次：

星级排名含义
★★★前 1,000英语的骨架词，必须秒认秒写
★★前 3,000高频，日常够用
★前 10,000有一定使用面，值得学
☆10,000 名以外低频或专有名词，认识就行，不必死练拼写

分级看「难度」，词频看「用得上用不上」。两者一起看： A1 + ★★★ = 必须掌握；B1 + ☆ = 知道就好。

记忆点

只在真正有钩子的时候才给，不是每个词都有。挑的角度按优先级：

  1. 合成词拆解 —— 最好用。sea + shell、jelly + fish（果冻鱼→水母）、bed + room
  2. 不发音字母 —— write 的 w 不发音、light 的 gh 不发音
  3. 易混 / 近音 —— draw / drawer、pen / pan
  4. 超常用搭配 —— climb a mountain、a grain of sand（顺便教不可数）

原则是帮孩子记住这个词，不是讲这个词的故事。词源（比如 pen 来自拉丁 penna「羽毛」）留到以后再说。

打印
